# 🎯 SN118 Bounty Board & Contributor Guide

Welcome to the **SN118 Subnet Bounty Board**! This guide outlines how contributors can participate, claim task bounties, submit verified pull requests, and receive automated subnet maintenance payouts.

---

## 📋 Active Bounty Categories

1. **Miner & Validator Optimization**: Performance tuning, GPU memory management, and latency reduction.
2. **Subnet Security & Auditing**: Verification of hotkey signatures, proof of work, and disputation mechanisms.
3. **Documentation & Tooling**: CLI enhancements, telemetry dashboards, and developer docs.

---

## 🛠️ How to Claim & Submit Bounties

1. **Browse Bounties**: Filter open GitHub issues with `label:bounty`.
2. **Reserve Task**: Comment `/claim` on the issue to request reservation.
3. **Submit PR**: Include `Fixes #IssueNumber` in your PR description.
4. **Payout**: Payouts are transferred automatically via SN118 maintenance treasury upon PR merge!
